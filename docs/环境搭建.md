# 环境搭建

> 当前环境定案：**RTX 5090（32GB，Blackwell sm_120）**，见 `docs/训练方案.md` §6.1。

## 依赖（Blackwell 硬性要求）

| 项 | 要求 | 原因 |
|---|---|---|
| Python | **3.10+**（建议 3.10，双方一致） | - |
| **PyTorch** | **≥ 2.7**（cu128 版） | 2.6 及更早不支持 sm_120（报 "no kernel image available"） |
| **CUDA** | **≥ 12.8** | Blackwell 需要 |
| 操作系统 | **Windows 原生 或 WSL2（推荐训练用）** | 训练栈 Linux 更稳；5090 在 WSL2 + vLLM 已验证可用 |
| 核心包 | `transformers` `trl` `peft` `datasets` `accelerate` `wandb` | - |
| **禁止** | FlashAttention-2、QLoRA/bitsandbytes | sm_120 不支持 FA2；NF4 在 Blackwell 有性能惩罚（32GB 显存下 LoRA 足够） |

## 步骤（Windows + WSL2 建议）

```bash
# 1.（WSL2 内）虚拟环境
python -m venv .venv
source .venv/bin/activate

# 2. 安装 PyTorch（cu128，5090 必须）
pip install torch --index-url https://download.pytorch.org/whl/cu128

# 3. 安装项目（开发模式）
pip install -e ".[dev]"

# 4. 密钥
cp .env.example .env               # 填 HF_TOKEN 与 WANDB_API_KEY

# 5. 验证（GPU 识别 + 冒烟）
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
make test && make lint
```

> Windows 原生装 PyTorch 2.7+（cu128）也可行；若 CUDA 报错，优先切 WSL2 重装。

## 硬件参考（5090 32GB）

| 方案 | 显存需求 | 结论 |
|---|---|---|
| **LoRA 7B（推荐）** | ~16GB | ✅ 可 batch 4 / seq 4096 |
| LoRA 14B（M2 升级） | ~28-30GB | ⚠️ 可跑但紧（batch 2 + checkpointing） |
| QLoRA 7B | ~10GB | 不需要（见训练方案 §4.2） |
| 全参微调 7B | >60GB | ❌ 单卡不可行 |

## 版本一致性（重要）

- `requirements.txt` 顶层依赖 + `requirements.lock` 全量锁定（`pip freeze` 生成）
- **双方机器依赖版本必须一致**（尤其 PyTorch ≥2.7 与 CUDA ≥12.8）；对方若为 24GB 以下卡，batch 按"每卡"定义回退 2 即可
- 升级依赖走 PR（config/ 类变更）

## 加速开关（sft.py 接线后启用，见训练方案 §5.2）

- `torch.compile`（PyTorch 2.7+，7B 提速 10~30%）
- 注意力：SDPA（默认），**不要开 flash_attention_2**
- `optim: adamw_torch_fused`（融合优化器）
